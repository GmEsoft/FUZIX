Run `python3 Kernel/tests/mm-buddy/check.py`. Compiles the actual optional buddy allocator under ASan/UBSan. The init range uses bottom-level node numbers `[BUDDY_SIZE, 2 * BUDDY_SIZE)`, with `buddy_ram` at the first leaf's address. Tests cover allocation sizes, full exhaustion, address conversions, splitting/coalescing, partial pools, and invalid requests. No enabled platform uses this allocator in the reviewed snapshot; platform integration and target builds remain unverified.
