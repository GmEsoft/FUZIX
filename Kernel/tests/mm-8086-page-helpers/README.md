Run `python3 Kernel/tests/mm-8086-page-helpers/check.py`. Extracts actual page-search, boot-range and copy/zero helpers and runs them under ASan/UBSan. Covers exhausted and short free runs, 512/640 KiB boot ranges, partial kernel pages, and overlapping page copies. The surrounding backend is explicitly draft code and retains incomplete process/EMM/fork/swap integration; this branch does not make the backend usable or claim a complete target build.
